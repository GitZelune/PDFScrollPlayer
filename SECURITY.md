# Security Policy

## Supported Versions

We recommend using the latest version of **PDFScrollPlayer**.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

- Open a [GitHub Security Advisory](https://github.com/GitZelune/PDFScrollPlayer/security/advisories/new), or
- Contact the maintainer via GitHub.

Please do **not** disclose vulnerabilities publicly until a fix has been released.
